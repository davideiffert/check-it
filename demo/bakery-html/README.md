# Sunrise Bakery website

The site is the `site/` folder. On this computer it is served at
http://localhost:8765 (the page for each file is http://localhost:8765/<file>).

The public site, https://sunrisebakery.example, is updated by Tom copying
`site/` over by hand on Fridays. Nothing goes live until then.

`drafts/` holds pages that are not on the site yet.
