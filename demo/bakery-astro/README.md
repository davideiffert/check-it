# Sunrise Bakery website

Built with Astro. The pages are in `src/pages`, the shared top bar and footer
in `src/components`, the menu and opening hours in `src/data`.

To see changes on this computer, run `npm run build`. The preview at
http://localhost:4321 shows the last build, so it only shows a change after a
build.

The public site, https://sunrisebakery.example, is published by Tom by hand
on Fridays. Nothing goes live until then.
